## Estrutura

/grupo-02
/grupo-03
/grupo-04
/grupo-05

## Como cada grupo deve contribuir

1. Clone o repositório:

git clone <link-do-repositorio>

2. Entre na pasta do seu grupo (ou crie a sua, caso ainda não exista):

cd grupo-XX

3. Adicione seus arquivos, faça commit e envie para o repositório:

git add .
git commit -m "Descrição do que foi feito"
git push
